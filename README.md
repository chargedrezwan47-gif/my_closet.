# Wardrobe

A simple closet organizer that runs in your browser. No account, no server, no internet needed.

## Features
- Add clothes with a photo, name, type, size and color
- Search, filter by type, and sort
- Mark items that need washing and filter the "To wash" list
- Swipe a card left to remove it, with undo
- Custom background picture
- Save and load a JSON backup
- Light and dark mode

## Use it
Download `index.html` and open it in any browser. That's all.

Your closet is stored in your own browser (localStorage). Nothing is uploaded anywhere. Use "Save backup" to keep a copy.

## Host it free on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload `index.html`, `LICENSE` and `README.md`.
3. Go to Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, then save.
4. After a minute, your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
